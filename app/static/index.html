THE IDEA IN PLAIN ENGLISH

If a simulated drone has a problem, can it retrace the places it has already visited?

This website lets you watch a pretend drone follow a route, remember each stop it reaches, and turn back through those remembered stops when you press Abort mission. It is an educational software simulation—not a real drone controller or proof of real-world safety.

Think of it like a walk with a shopping list: the Queue is the list of places still to visit; the Stack is the trail of places already reached. If the walk is interrupted, retrace that trail in reverse.

        A SIMPLE WAY TO EXPLAIN THIS PROJECT

        What should I tell my faculty?

        “This is a website that simulates a drone following a list of destinations. It records a checkpoint only after reaching a destination. If I trigger an emergency, it stops taking new destinations and returns through the checkpoints in reverse order. I built it to demonstrate a Queue, a Stack, and safe software state transitions. It is a simulation, not real flight-control software.”
        Queue = upcoming planDestinations are handled in the order they were added.
        Stack = visited trailThe newest reached checkpoint is the first one used on the way back.
        Abort = stop and retracePending destinations are cleared; already reached checkpoints remain available for rollback.
